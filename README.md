# Raja Rajeswari Matta | QA Portfolio

A three-page portfolio shaped around the visual reference supplied by the user: pale lavender background, centered pill navigation, condensed headings, purple accents, and a bordered profile card. Content is based on Rajeswari's resume.

## View locally

Open `index.html` in a browser. Navigation leads to `about.html` and `work.html`. The About page's View Resume button downloads the included original DOCX. Fonts use Google Fonts when online, with system fallbacks offline.

## Files

Keep all files together when uploading to GitHub or Netlify. No build step is needed. The theme switch works in both light and dark modes.

Please review the resume, contact details, and employment wording with Rajeswari before publishing. This folder has not been deployed.
