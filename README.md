# Raja Rajeswari Matta — QA Portfolio

A responsive, single-page portfolio based on the supplied resume. It highlights documented roles and testing work without inventing project results or metrics.

## Open locally

Open `index.html` in a browser. No installation, build step, account, or network connection is needed. The only external links are email, phone, and LinkedIn.

## Customize

Edit copy and links in `index.html` and colors/layout in `styles.css`. The work section presents representative responsibilities from the resume, not independently published case studies. Please review the contact details and wording with Rajeswari before making the site public.
